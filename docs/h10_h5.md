# Post Tower Continuation and Free Roam — H10 dialogue purchase (H5)

Installed 25 October 2026. Full script compilation, native resource readback,
offline checks and guarded installation passed. In-game UI verification is pending.

At V's unpaid apartment door inside H10, the offer now uses the game's native
on-screen dialogue choices:

- **Purchase apartment — €$25,000** selects the purchase explicitly.
- **Not now** dismisses the offer until V leaves the entrance area and returns.
- With insufficient funds, an inactive **Not enough money — €$25,000 required**
  row replaces the purchase option. No payment is attempted.

Approaching the door only makes the choices available. There is no automatic
confirmation window, input-capturing popup or proximity-triggered debit.
The native choice is attached to the exact existing apartment door, with a
3.5-metre activation range and 5-metre indication range. Normal control, the
released loading cover and the existing entrance validation are also required.
An already owned apartment does not offer another purchase.

## Behaviour and payment safeguards

The native scene has no NPC or player actors. It neither acquires V nor changes
the camera or gameplay tier. Its entry only presents choices and starts a
readiness-cancellation watcher. Only the purchase choice reaches the request
writer; Not now uses a separate cancellation request. Walking away, entering
a menu or losing eligibility removes readiness and ends the choice scene.

The new `HousingDialogueH5` system consumes and disarms the request before
calling the original `HousingState.Purchase` operation. The current exact door,
player context, fixed displayed quote and normal purchase eligibility are
checked again. The original operation still verifies funds, attempts one debit,
records the result and reconciles entitlement. Its entire compiled class is
unchanged. A refused purchase is not automatically retried; step away and return.

Attach/load resets discard old pending UI requests before arming a new offer.
The retired H3 popup callback and old door-action handler are inert. The duplicate
device purchase action is no longer added. DLC apartment purchasing, the website
guard, H10 unpaid locking/inside egress, the for-sale/owned icon and paid-only
services remain unchanged. FS1's Fred repair is retained.
