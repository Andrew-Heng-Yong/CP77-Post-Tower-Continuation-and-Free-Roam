# Skippy restoration audit against the installed vanilla game and Cyberpunk Wiki

**28 October 2026. Read-only audit.** The current LC4 installation still contains the SC3 Skippy controller and S23 story adapters. A fresh scan of all 133 installed archives found exactly one provider for each of six checked vanilla MQ007 resources and four checked restored resources. The installed S23 script and combined archive match their pinned hashes. The SC3 owner is byte-identical to the validated candidate. The assessment and current resource census are in `diagnostics/skippy_vanilla_wiki_audit_20261028_01/`.

The [Cyberpunk Wiki Skippy article](https://cyberpunk.fandom.com/wiki/Skippy) describes pickup mode selection, the 50-neutralization conversation, occasional autonomous shots, and the later request to return the gun. The [Machine Gun article](https://cyberpunk.fandom.com/wiki/Machine_Gun) describes Regina's delivery and later retrieval of a gun without its AI. The wiki is a behavior reference; the extracted resources from this installed game determine the actual authored graph. Direct wiki page loading was blocked by the site, so the cited behavior came from the search index's crawled article text.

## Concrete story-admission gap

The installed `MQ007_RESUME` driver requires `PTFRS23_MQ007_ModeTalkConfirmed=1` **and** a fully valid exact progress sample. Its data has identical minimum and maximum values for lethal/nonlethal/total counters: **11/51/95**. The 27 October serialized `ManualSave-23` instead has total **97** and no confirmation fact, so that saved snapshot cannot enter the resume owner. A later recorded run advanced total to **100** and lethal to **16**; if that progress is carried by the save, it also falls outside the exact seam. These are observed mismatches, not a read of the current save. The user has separately confirmed the mode conversation, but that statement does not set the saved mod fact. This exact-counter gate is materially narrower than vanilla's continuing story after the mode conversation and can leave a progressed restored gun without the Machine Gun continuation. It should be reviewed before any proposed fix; this audit did not change it.

The previous [recorded-log review](skippy_restoration_log_review_20261028.md) remains the runtime evidence. Its pre-ending run still had mods installed and is a gameplay reference, not a clean unmodded baseline. The source scan found one native provider for root, comments, expression reset, both scenes and hologram prop, with no mod override; it also found one provider for each examined SC3/S23 private resource. The current archive's only LC4 member change was the credits phase, so Skippy's packed bytes remain the SC3/WA3 versions. No game launch, installed-file edit, save/fact edit, implementation, or in-game test request was part of this audit.
