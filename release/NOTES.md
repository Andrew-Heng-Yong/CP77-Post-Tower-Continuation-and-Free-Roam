# Post Tower Continuation and Free Roam pre-alpha - 23 October 2026

Download **TowerContinuation-v0.1.0-prealpha.20261023.zip** under **Assets** for the
mod. The automatic **Source code** archives are developer downloads.

This full mod snapshot contains the existing Tower continuation and restoration
components through **Housing H1 + S28**, including their runtime scripts and
packed archives. The 109 mod files match the recorded development installation.
The ZIP includes installation instructions, a file manifest, and the beta save
contract; a separate SHA-256 checksum accompanies it.

**Experimental pre-alpha, not the planned beta.** The newest changes still need
live playtesting. Actual initial-transition and save-upgrade fixtures are pending.
Use a separate test save. Save continuity for the future beta remains a release
requirement, not a claim of completed testing for this pre-alpha.

Read [installation instructions and exact dependencies](https://github.com/Andrew-Heng-Yong/CP77-Post-Tower-Continuation-and-Free-Roam/blob/v0.1.0-prealpha.20261023/release/INSTALL.md)
before installing. This package depends on the documented experimental Patch 2.5
framework stack. Framework binaries and unrelated mods are not included.

Known limits include incomplete final whitelist/prerequisite enforcement,
18 selected side jobs without added implementation, unsupported unfinished
quest paths that defer, and pending housing/reload verification. The source
repository's latest status records contain the detailed development history.
