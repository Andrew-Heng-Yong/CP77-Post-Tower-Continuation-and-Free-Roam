# Tower Continuation Alpha Test — 24 October 2026

Download **TowerContinuation-v0.1.1-alpha.20261024.zip** under **Assets** for
the playable mod package. GitHub's automatic Source code archives are for
development. A SHA-256 checksum is provided alongside the ZIP.

This full 117-file snapshot updates the 23 October pre-alpha with the history
snapshot fallback, loading cover and H10 housing purchase work, along with the
current packed quest and world files. The history snapshot CET loader is included;
its generated save-specific JSON files are excluded.

The 24 October local logs show the H10 purchase offer, payment receipt and icon
switching to owned. The current purchase prompt opens automatically at V's
private H10 apartment door. A conversation-style purchase choice is planned for
a later version. Physical door access, apartment services, reload behavior and
full quest restoration have not been verified by this package.

**Alpha test, not beta.** Use a separate test save. This release
needs the documented experimental Patch 2.5 framework stack, including local
Codeware and ArchiveXL patches; framework binaries are not included. The ZIP's
`TowerContinuation/INSTALL.md` lists the dependency and installation details.
Save continuity into a future stable version remains a requirement, not a
completed compatibility claim.
