# Open Beta 0.2.0 — installation

1. Close the game and launcher and install the required frameworks.
2. Extract the beta ZIP. It contains only `archive`, `bin`, `r6` and `readme`.
3. For an older installation, ask an AI to read `readme/AI_CLEANUP_INSTRUCTIONS.md`, or follow `readme/MANUAL_CLEANUP_INSTRUCTIONS.md` yourself. The included JSON lists supply the cleanup paths and hashes. No old ZIP or backup is required.
4. Merge `archive`, `bin` and `r6` into the game folder and choose **Replace**.
5. If Virtual Atelier is installed, apply or verify the required correction documented in the manual guide. There are no scripts in the ZIP.
6. Test with a separate manual save.

The tested stack is Cyberpunk 2077 Patch 2.5 with Phantom Liberty, RED4ext 1.31.0, redscript 0.5.32, CET 1.38.0, Codeware 1.21.1, ArchiveXL 1.28.0 and TweakXL 1.12.0.

Installed filenames stay stable: merge future full updates and choose Replace. Beta saves are expected to remain supported by future versions; each successor must preserve or explicitly migrate saved state and pass upgrade checks.
