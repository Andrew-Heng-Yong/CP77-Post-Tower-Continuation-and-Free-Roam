# Post Tower Continuation and Free Roam — Open Beta 0.2.0

Continue free roam after The Tower ending while retaining its consequences.
This full 51-file release brings together the post-Tower transition, world
population and actions, bounded quest restoration, housing and restriction
systems, and the Viktor clinic-door repair. The user has confirmed the door
opens in their post-Tower run. The previous WA3 NPC and computer compatibility
fixes were also reported working in an earlier run.

There are **no known fatal bugs** in the current tested build.

Known issues:

- Some world assets may be missing.
- Some minor NPC or world actions may be missing.
- Some side jobs may have misconfigured entry handlers and fail to start from
  an eligible-looking save.
- Skippy's one-time *Machine Gun* return has a narrow saved-state gate on some
  progressed saves; its full return path remains unverified.

Saves made with this Open Beta are supported by future updates of this mod.
Players will not need a new playthrough solely to update the mod. Future
versions must preserve or explicitly migrate the saved state; each successor
must pass its save-upgrade checks before release.

Installed filenames stay fixed across future versions: merge a future full
update into the game folder and choose **Replace the files in the destination**.
Version numbers appear only in the outer ZIP name.

For an older installation, ask an AI to clean the obsolete mod files.
The beta includes `readme/AI_CLEANUP_INSTRUCTIONS.md` for the AI to
read, plus the necessary file manifests. No old ZIP, backup or cleanup script
is required. Then merge the beta folders and choose Replace.
The required Atelier edit is documented in `readme/MANUAL_CLEANUP_INSTRUCTIONS.md`. The ZIP contains only archive, bin, r6 and readme, with no installer or cleanup scripts or other extras.
