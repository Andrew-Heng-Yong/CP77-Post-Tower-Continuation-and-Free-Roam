# Change log

## Open Beta 0.2.0 — prepared 29 October 2026

- Packaging revision: replaced cleanup automation with an AI cleanup guide and
  known obsolete-file hashes. No old ZIP or backups are required. The required
  Atelier correction has its own patch tool; it does not clean old files.

- Prepared the full 51-file consolidated download through VD1. The user confirms
  Viktor's clinic door now opens after The Tower.
- Integrated the required CO1 correction into installation whenever Virtual
  Atelier is present. Clean installs, alpha migration with 114 retired paths,
  the mandatory Atelier patch, unknown-version rejection and rollback passed
  four fixture cases and 16 actions. The game installation and saves were not
  modified by release preparation.
- Preserved installed filenames and paths. Future complete updates merge into
  the game folder with Replace; only the outer ZIP carries the version number.
- Recorded no known fatal bugs, possible missing assets and minor actions, and
  misconfigured side-job entry handlers. Skippy's narrow progressed-save gate
  is also documented.
- Committed to supporting beta saves in future mod updates, with preservation
  or explicit migration and successor upgrade checks required.
- The ZIP and checksum are prepared locally. No GitHub release is published by
  this preparation. See [installation](release/INSTALL-v0.2.0-beta.md) and
  [release notes](release/NOTES-v0.2.0-beta.md).
