15 November 2026, Toronto. This is a bounded read-only investigation of the installed `RD10_MID_QUEST_RESUME_RETIRED` build. The user reported that visiting Dexter's body and opening or scanning the nearby freezer did not start KOLD MIRAGE. The earlier 8 November KM2 acceptance and delayed-marker report concern another attempt; they do not certify this save.

The user reports no KOLD map marker and only one undiscovered entry overall. The freezer action and UI counts are user reports; exact Open versus Scan and screenshots are not available.

**Finding:** the save and live reads place KOLD between Issued and Entered, with its original content wait still registered. The evidence is consistent with `MinorQuestAndSts` not being granted on this fixture; the two unblocked getters show only that global activation is not blocked. They do not expose token ownership, queue state or the scheduler's reason. This is a live failure to start KOLD on the reported route, including its reported missing marker, not a proved missing map-pin writer or lost private handler. The single-undiscovered UI report does not establish a save-specific expected count. No condition was removed or token/fact forced.
