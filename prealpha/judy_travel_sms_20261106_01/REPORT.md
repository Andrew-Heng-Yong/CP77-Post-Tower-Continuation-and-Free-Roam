# Judy’s travel texts after The Tower

Judy’s Oregon, car photo and Seattle texts are the three delayed travel phases under Pyramid Song’s friendship route. The user identified the Seattle text in post-Tower free roam. The installed provider scan found the same four native payloads as the pinned exports, covering the three senders and their parent. The combined archive adds only the three sender overrides. [Provider pins](serialized_01/manifest.json)

Each sender checks the existing handoff markers `PostTowerFreeRoamActive=1` and `PTFRP0_DR13=1`, alongside the native completed, inactive and 2079 facts. The checks run after the parent’s delay and content wait, before a new exchange opens. In Oregon and Seattle they also run after the child’s content-token handoff and after each native reply wait. Before the handoff, each original branch and fan-out runs as authored.

A blocked entry uses the existing terminating output. A blocked continuation of a started conversation uses the native expiry path, which closes active reply groups and reaches the same terminating output. Already delivered messages stay in the journal. The parent retains its timers and progression between threads. All original node IDs, journal paths and native cleanup nodes are preserved. The change introduces no new owner, fact writer, script or ArchiveXL registration.
