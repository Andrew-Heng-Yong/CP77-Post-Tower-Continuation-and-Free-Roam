# Native world support for the MS31 Over the Edge test

The helper reads the two native world prefab leases for the saved `mq049` phase and the world backing those same resolved references. It checks `#mq049_pr_main` and `#mq049_pr_reyes` after the stock world update. The stock loader owns the leases and the stock phase owns the authored world changes. The helper observes state inside native locks and returns a value snapshot. The caller binds the sample to the same retained session, loader, world and ordered reference pair.

## Lease and world readback

- The quest loader sits at `QuestsSystem+0x100`. Its `+0xC8` world is the pointer passed to the native world producer by `0x699498`. The world update at `0x69B1FC` receives that world at `this+0x48`, runs native evaluation and drains native desired work. The hook reads after that call returns and validates both exact vtables.
- The stock loaded phase uses its `PhaseInstance+0x84` ticket. A fresh prior phase can also own a handler ticket at `+0x54`. Stock restore in mode 2 uses the phase instance ticket. The source phase has a zero unfreezing trigger, so the mode 2 path parks the phase handler without acquiring a second ticket. Capture each ticket the old phase actually owns and require every captured ticket and its ready entries to drain. A positive remaining count represents native holders outside the captured tickets and stays eligible for shared ownership.
- The replacement ticket must be live, differ from the retired tickets, match the ordered old resolved references and have drained its pending, unresolved and ready work. Loader and world identity must match. An absent or locked record defers the attempt.
- On the post-update hook, both references must have nonempty native world indices, be desired and have no queued request for the sampled references. Each referenced sector must be in bounds, requested and evaluated. Every requested node in these sectors must be settled and each reference needs at least one requested node with ready data. The native aggregate also uses a terminal result for an empty or missing index. The index and sector checks disambiguate that result for the handoff. The snapshot checks settled native group support. Individual authored trigger and variant placement are observations for the game test.

The fixture ran 21 assertions using the exact game image's native index lookup and desired query in synthetic world and loader memory. It covers one- and two-ticket old owners, a single-ticket replacement, old callback and shared count handling, unsupported and pending world records, native locking and world changes. The receipt also pins the world array layout and condition producer teardown instructions. It records `game_runtime_exercised` as false.
