# Candidate and evidence scope

Follow root AGENTS.md. `docs/knowledge/current-state.md` selects the current consolidated candidate. A higher candidate number, directory date or script name does not select production. Read the component assessment, manifest, input hashes, source diff, known limitations and rollback order before touching it.

Treat recorded candidates, packages, source inventories, compile results and receipts as pinned evidence. Historical scripts often refuse existing paths or contain assumptions for retired baselines. Develop a fresh successor with current-input checks; do not bypass guards, remove backups, overwrite evidence or rerun a builder to make an old PASS appear current.

Preserve the whole current consolidated source and reviewed corrective donors, changing only the explicit resource allowlist. Preserve saved paths/node/field/receipt identities and old executing descendants. Rebuild copied nested edges and validate root/ancestor prefab obligations. Compilation, static checks, fixture recovery, installation verification and live behavior are separate gates. Deployment requires its own authorization and current game-closed/hash/preservation checks.
