# Misty’s rooftop chair crash

On 18 November the user reported a missing Sit prompt. The game then crashed at 12:27 a.m. near V’s chair. The crash report puts V at `(-1541.24, 1203.52, 58.60)`, 2.3 metres from the chair’s workspot origin. The report’s attached save matches AutoSave-10 byte for byte. That save records `PTFRMistySeat_Registered=1` and was made before the crash. The session log confirms ArchiveXL merged the seat phase and REDscript compiled. [Crash evidence](crash_evidence.json)

The native dump identifies the private chair scene and the `fpp_idle_stand` lookup used by the stand-up transition. The lookup reached index 1 with two animation-name rows and one loaded animation set. The engine raised a read access violation at `Cyberpunk2077.exe+0x257b06`. The original scene has both rows. The earlier Streetkid donor dropped the female V animation-set reference and retained its lookup row. The rooftop build inherited that mismatch.

The repaired scene restores the original female V set reference from the vanilla Kerry chair scene. Both sets from the installed game contain `fpp_idle_stand`. An exact decoded diff found just the added reference. The choice graph, workspot, player bindings, exit and saved identifiers match the installed scene. The new archive contains 1,751 members. All 1,750 other members match the installed bytes, and the complete staged package differs in one file. The deployed ArchiveXL registration and REDscript verified against the existing installation. [Staged package](candidate_01/core_manifest.json) · [Archive readback](work/pack_01/readback.json)

The game crashed again at 12:50:19 a.m. Toronto time on 18 November while the original archive was installed. The new dump independently identified the same private scene, animation, lookup index and table counts at the same fault address. ArchiveXL logged the rooftop phase at 12:48:53. Both crash reports contained a copy of AutoSave-10. Neither dump records whether the Sit prompt appeared. [Second crash evidence](repeat_crash.json)

The repaired archive was installed after the second crash with the game and launcher closed. Three isolated fixtures verified clean rollback, recovery after an interrupted installation and refusal to overwrite an unexpected archive. The installed 51 Core files and 93 protected files passed readback. All 523 save files matched their pre-install hashes, and the predecessor archive was backed up and verified. The visible Sit prompt, seated pose, Get Up and a second use still need an in-game check.
