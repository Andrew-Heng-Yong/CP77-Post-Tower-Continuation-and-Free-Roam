## How to run the playtest

1. Keep the original saves as masters and make separate manual working saves for each checkpoint. Record the slot and displayed time, the exact objective, and any visible message or item state.
2. Earn the checkpoint through ordinary play or find a save that already has it. Complete The Tower normally on the working branch, through credits and cleanup. Take a new manual save in post-Tower free roam before advancing the target quest. For Bartmoss, reuse the existing post-Tower fixture after QR20 is installed.
3. For Brendan, keep the post-Dumpster and post-Spray checkpoints separate. They test different starts. Independent quests can share a run when their prerequisites coexist. When a route naturally reaches a saveable pending stage, one reload there can cover persistence. Where the route awards something, record the reward and check for a duplicate on reload.
4. If you run a fact-forced experiment, keep it in a separate disposable branch and label it **SMOKE ONLY**. Record the original and edited values. An edit can show a response to that value. It cannot establish earned eligibility, native quest ownership, message listeners, timers or reward history. Keep Tower progression, PTFR receipts and the real continuation fixtures native.
