# Exact mid-journey resume archive

15 November 2026. The experimental exact-resume feature is detached from the game. The workspace archive contains the v0.1.13 native DLL, four checkpoint exports, the experiment’s standalone plugin log, the compiled script cache that contained the experiment, and the four original shared script files. All 11 archived files were read back against their pre-change SHA-256 hashes. [Installed manifest and archive paths](stage_02/deployment_01/installed_manifest_01.json)

The game uses its RD10 restoration archive and normal pre-Tower history capture. The earlier quest-specific rules that reopen an already-earned objective remain part of RD10. Four Core scripts have reverted to their pre-experiment logic. The history class retains eight existing saved field declarations for compatibility with saves written during the experiment. Those fields have no capture, export, or restoration code. [Prepared sources and preserved fields](stage_02/preparation.json)

All 148 registered REDscript sources compiled offline and the compiled image contains no active experimental resume symbols. Startup and save loading with the detached build remain untested. The archive transaction passed 12 fixture actions across five isolated trees. Post-install readback verified all 51 Core files, all 26 dependencies, the archive copies, and the absence of all seven detached files. All 415 save names and hashes matched across the transaction. Exact file rollback is ready at the recorded baseline.
