# REDscript source scope

Follow root AGENTS.md and `docs/knowledge/redscript-toolchain.md`. This directory retains component/versioned sources; not every folder is active. Match the current consolidated package and exact compile-input manifest before selecting sources. Do not concatenate or compile every prototype together.

Preserve persistent fields/classes, epochs, save metadata and exactly-once migration receipts. Keep no-vitals paths free of HP/stamina writes. Do not refund unknown modded perks, destroy owned equipment or revive Tower/Relic facts to enforce a profile.

Changed source needs a fresh complete dependency census and isolated SCC cache, including installed external/SDK sources. Never compile into the game cache as a routine check. Historical 112-input compilation is bounded evidence, not proof that today's inputs or a proposed source change compiles.
